# The Quantum Break-In

A top-down 2D browser game that teaches the core ideas of quantum computing through a heist.

Finn is broke and picks the richest house on Marigold Lane to rob. Bad choice: it belongs to Professor Quark, a mad scientist who guards everything with quantum locks. Finn's childhood friend Maya, a quantum physicist, is on the phone and teaches him the physics he needs at each lock. The loot in the vault turns out to be Schrödinger's cat.

No quantum background is needed. Nothing can be failed, and every puzzle has three levels of hints.

## Play

- **Offline:** download `index.html` and double-click it. The whole game is that one file; there is nothing to install and no internet connection is needed.
- **Online:** upload `index.html` to any static host (see [Hosting](#hosting)).

Progress saves automatically in the browser, so you can stop and continue later.

## Controls

| Action | Keyboard | Mouse / touch |
|---|---|---|
| Move | `W` `A` `S` `D` or arrow keys | Click or tap where you want to go |
| Interact | `E` or `Space` | Click or tap the object, or the button that appears |
| Advance dialogue | `Space` or `Enter` | Click or tap the dialogue box |
| Close a window | `Esc` | Close button |

The plan of the house is in the top-right corner. Rooms appear as you enter them, and a blinking amber dot marks the next goal.

## The seven locks

| # | Where | Lock | Concept taught |
|---|---|---|---|
| 1 | Garden gate | Coin Lock | Superposition and measurement |
| 2 | Front door | Porch Sensors | The Bloch sphere and phase |
| 3 | Lab door | Gate Lock (3 steps) | Quantum gates X, Z, H; H·Z·H = X |
| 4 | Corridor | Interference Panel (2 steps) | Interference |
| 5 | Library | Key Cabinet (2 steps) | Grover's search |
| 6 | Study | Glass Chamber (3 steps) | Entanglement and teleportation |
| 7 | Vault | Resonance Dial (2 steps) | Phase estimation |

There are also three of the professor's notes to find, a notebook that collects what you have learned, and a cat that follows you home.

## What makes it accurate

Every puzzle runs on a real state-vector simulator written for the game (complex amplitudes, up to 6 qubits). Measurement outcomes follow the Born rule, the teleportation puzzle simulates the actual three-qubit circuit, Grover's search uses the true mark-and-mirror steps, and the vault uses iterative phase estimation. Where the game shows something a real quantum computer could not show (for example the "X-ray" amplitude bars), it says so.

One deliberate simplification: in the Glass Chamber, fading entanglement is modelled as a simple exponential loss of quality over time.

## Features

- Walkable mansion with eight areas, fog on unvisited rooms, mini-map and goal marker
- Story dialogue with three characters and a typewriter effect
- Thirteen hands-on mini-games across seven locks
- Three-tier hints on every step, and a notebook of concepts learned
- Sound effects synthesised in the browser (no audio files); one-click mute
- Works with keyboard, mouse or touch, on desktop and phone screens
- Single file, no dependencies, no network requests, works offline

## Project structure

`index.html` is generated by joining the source files in this order:

| File | Contents |
|---|---|
| `head.html` | Page markup and all CSS |
| `sim.js` | Configuration, seeded random numbers, the quantum simulator |
| `widgets.js` | Reusable canvas widgets: Bloch sphere, amplitude bars, histogram, dials, circuit board |
| `comp1.js`, `comp2.js`, `comp3.js` | The mini-game players (one function per puzzle type) |
| `data.js` | The house map, objects, dialogue, and every lock's steps, explanations and hints |
| `game.js` | Movement, camera, dialogue, sound, puzzle screen, ending, menus |
| `build.sh` | Joins the files into `index.html` (and `preview.html`) |

To change story text, hints or which puzzles a lock contains, edit `data.js`. To rebuild, run `build.sh` (the paths at the top of the script need to point at your copy of the folder).

`preview.html` is a developer build that skips the house and opens the Glass Chamber and Vault mini-games directly.

## Hosting

The game is a static file, so any static host works:

- **itch.io:** create an HTML project, upload a zip containing `index.html`, and mark it as playable in the browser.

## Useful options

- Add `?seed=1234` to the address to get the same puzzle values every time (useful for demos).
- The Menu button shows the current seed and has a "Start over" option.

## Browser support

Any current version of Chrome, Edge, Firefox or Safari. Sound starts after the first click or key press, as browsers require.

## Testing

During development a scripted player completed the full game through the real controls, at desktop and phone sizes and on several puzzle seeds. It checks that the game is completable and error-free; it does not measure how the difficulty feels to a human player.
